# SwarmLink documentation

Start with [Document 01](01-dashboard-overview.md) for a simple explanation of the first dashboard version and the scripts behind it.

- [Document 02 - Live robot guide](02-live-robot-guide.md): start and stop the dashboard, use its controls, and connect on another network.
- [Document 03 - Robot setup](03-robot-setup.md): manual setup and checks for four robots.
- [Document 04 - Data contract](04-data-contract.md): message fields, units, and validation rules.
- [Document 05 - Operations](05-operations.md): saved data, retries, recovery, and limitations.
- [Document 06 - Validation](06-validation.md): automated checks and tests with the physical robot.
- [Document 07 - Set up a new robot](07-new-robot-setup.md): use the launcher over Ethernet, Wi-Fi, or USB. Includes a direct-cable IP example and simple troubleshooting steps.

The code and Windows launchers are in [data-engineering](../data-engineering/README.md). The [root README](../README.md) links to all seven documents. The logo is in [images/swarmlink-logo.png](images/swarmlink-logo.png).
